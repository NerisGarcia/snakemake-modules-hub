# Taxa names

UBA629_sp005465875 its changed to Candidatus_Lachnocurva_vaginae

The module takes sample IDs from `sample_file` and paired files from `raw_dir`.
`pairend_extension_pattern` supplies the read-specific part (`{read}` is 1 or
2), followed by `input_extension`. An optional `unpaired_input_pattern` uses
`{sample}` and the same extension. Set `virgo2_script` to the installed
VIRGO2.py path. Results are written beneath `out_dir/VIRGO2`.
